## 7. Decisions & why
- **Next.js App Router (not Pages):** Supports server components, built-in middleware, better DX for modern React patterns
- **Turbopack for dev:** Next.js 15 default; much faster than Webpack for fast iteration
- **React 19:** Latest stable; hooks-only codebase, no class components
- **Tailwind 4 + PostCSS plugin:** Latest engine, smaller bundle, faster builds
- **Zod + react-hook-form:** Type-safe form validation with minimal runtime overhead; strongly typed errors
- **Context for options caching:** Dropdown data (vehicle makes/models, etc.) fetched once and cached in OptionsCacheContext to avoid refetching on re-renders
- **PDF via @react-pdf/renderer:** Generates quotes as JSX-like PDF structure; matches component styling; avoids iframe/canvas complexity
- **Token in cookies:** Stateless auth; middleware checks presence; no session management overhead
- **Separate service layer:** Decouples HTTP calls from components; easier to test and refactor
